
#### API Endpoints:
- ✅ `GET /api/health` - Health check
- ✅ `GET /api/services` - Список услуг
- ✅ `GET /api/services/:id` - Услуга по ID
- ✅ `POST /api/bookings` - Создать запись
- ✅ `GET /api/bookings` - Список записей

#### База данных (Prisma + MySQL):
- ✅ **User** - Пользователи (с ролями CLIENT/ADMIN)
- ✅ **Service** - Услуги автомойки
- ✅ **Booking** - Записи на мойку (с валидацией времени)
- ✅ **Payment** - Платежи (готово для интеграции)

#### Валидация:
- ✅ express-validator для проверки данных
- ✅ Проверка дубликатов записей на одно время
- ✅ Валидация телефона (+7XXXXXXXXXX)

## 🚀 Что дальше (следующие шаги):

### Перед запуском:
1. ⚠️ Установите и запустите MySQL
2. ⚠️ Создайте базу данных `detailing_volgograd`
3. ⚠️ Обновите `DATABASE_URL` в `.env`

### Инициализация:
```bash
cd server
npm run prisma:generate  # Генерация Prisma Client
npm run prisma:migrate   # Создание таблиц
npm run seed             # Заполнение тестовыми данными
```

### Запуск:
```bash
# Терминал 1 - Backend
cd server && npm run dev

# Терминал 2 - Frontend
cd client && npm run dev
```
