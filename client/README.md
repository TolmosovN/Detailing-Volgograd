## Frontend (Next.js + Tailwind)

Этот каталог содержит фронтенд-проект автомойки на Next.js 14 (App Router) и TypeScript.

### Быстрый старт

1. Установить зависимости:

```bash
cd client
npm install
```

2. Запустить режим разработки:

```bash
npm run dev
```

3. Открыть приложение в браузере по адресу `http://localhost:3000`.

### Структура

- `app/` — страницы и layout (App Router).
- `src/features/` — функциональные модули (например, услуги, запись).
- `src/widgets/` — составные блоки страниц (`Header`, `Footer` и т.д.).
- `src/shared/` — переиспользуемые элементы (`ui`, утилиты, конфиг и пр.).
