## 🧪 ПРОТЕСТИРУЙТЕ СЕЙЧАС:

### Создайте запись на мойку:

1. Откройте http://localhost:3000
2. Перейдите в "Записаться"
3. Заполните форму
4. Нажмите "Записаться"
5. Увидите: "✅ Запись успешно создана!"

### Просмотрите данные в БД:

```bash
cd server
npm run prisma:studio
```

Откроется http://localhost:5555 - увидите вашу запись в таблице bookings!

### 4. Запуск приложения
- ⏸️ Запустить backend (npm run dev)
- ⏸️ Запустить frontend (npm run dev)
