# 🧪 Как протестировать платежи ПРЯМО СЕЙЧАС

## 🎯 Быстрая инструкция для Mock режима

### Шаг 1: Убедитесь что серверы запущены

**Backend (терминал 1):**
```bash
cd server
npm run dev
```
Должен работать на `http://localhost:5000`

**Frontend (терминал 2):**
```bash
cd client
npm run dev
```
Должен работать на `http://localhost:3000`

---

### Шаг 2: Создайте тестовую запись

1. Откройте http://localhost:3000
2. Нажмите **"Записаться"** (или перейдите на `/booking`)
3. Заполните форму:
   - Выберите услугу (например, "Комплексная мойка")
   - Выберите дату
   - Выберите время
   - Укажите марку авто
   - Введите телефон и email
4. Нажмите **"Отправить запрос"**

**Результат:** 
- ✅ Создается запись (Booking)
- ✅ Автоматически создается платеж (Payment) со статусом PENDING
- 🔄 Вы перенаправляетесь на страницу оплаты

---

### Шаг 3: Оплатите запись

Вы окажетесь на странице `/payment/[bookingId]`

**Что вы увидите:**
```
┌─────────────────────────────────┐
│     Оплата записи               │
├─────────────────────────────────┤
│ Услуга: Комплексная мойка       │
│ Описание: ...                   │
│                                 │
│ Дата: 15.02.2026                │
│ Время: 14:00                    │
│                                 │
│ Клиент: Иван Иванов             │
│ Email: ivan@example.com         │
│                                 │
│ Итого к оплате: 1500 ₽          │
│                                 │
│  [Оплатить картой]              │
└─────────────────────────────────┘
```

**Что делать:**
1. Нажмите кнопку **"Оплатить картой"**
2. **ПОДОЖДИТЕ 3-4 СЕКУНДЫ** ⏳
3. Ничего больше делать НЕ нужно!

---

### Шаг 4: Автоматическое подтверждение

**Что происходит за эти 3-4 секунды:**

```
Секунда 0: Вы нажали "Оплатить"
    ↓
    🔄 Кнопка становится "Обработка..."
    ↓
Секунда 1-3: Backend обрабатывает
    ↓
    ✅ Платеж меняется: PENDING → PAID
    ✅ Запись меняется: PENDING → CONFIRMED
    ↓
Секунда 3-4: Редирект
    ↓
    🎉 Страница успеха!
```

---

### Шаг 5: Страница успеха

Вы автоматически попадаете на `/payment/success?bookingId=X`

**Что вы увидите:**
```

├─────────────────────────────────┤
│ Номер заказа: #123              │

│ Статус: PAID (Оплачено)         │
│                                 │
│ Услуга: Комплексная мойка       │
│ Дата: 15.02.2026                │
│ Время: 14:00                    │
│                                 │
│ [Перейти в профиль]             │
│ [На главную]                    │
└─────────────────────────────────┘
```

---

### Шаг 6: Проверьте в профиле

1. Перейдите в **"Профиль"** (`/profile`)
2. Найдите вашу запись

**Должно быть:**
- Статус: **CONFIRMED** (Подтверждена) ✅
- Оплата: **PAID** (Оплачена) ✅
- Показана зеленая метка

1. Таблица `bookings` → ваша запись должна быть со статусом `CONFIRMED`

## ❓ Частые вопросы

### Q: Я нажал "Оплатить", но ничего не происходит
**A:** Подождите 3-4 секунды. В mock режиме есть искусственная задержка.

### Q: Меня не перенаправило на страницу успеха
**A:** 
1. Проверьте консоль браузера (F12) на ошибки
2. Проверьте что backend запущен (`http://localhost:5000`)
3. Проверьте файл `server/.env` - должно быть `PAYMENT_MODE=mock`

### Q: Как понять что платеж оплачен?
**A:** Несколько способов:
1. Вас перенаправило на `/payment/success` ✅
2. В профиле запись показана как "Подтверждена"
3. В Prisma Studio статус `PAID`

### Q: Нужно ли вводить данные карты?
**A:** **НЕТ!** В mock режиме никакие данные вводить НЕ нужно. Просто нажмите кнопку и подождите.

### Q: Это реальная оплата?
**A:** **НЕТ!** Это имитация. Никакие деньги не списываются. Для реальной оплаты нужно переключиться на production режим (см. файл `PAYMENT_SETUP.md`).

## 🐛 Если что-то пошло не так

### Проверьте терминалы:

**Backend терминал должен показывать:**
```
Server is running on port 5000
Connected to database
POST /api/payments/create 201
POST /api/payments/123/confirm 200
```

**Frontend терминал должен показывать:**
```
✓ Ready in 3s
○ Compiling /payment/[id] ...
✓ Compiled /payment/[id] in 1.2s
```

### Очистите кэш:

1. Ctrl+Shift+R (жесткая перезагрузка)
2. Закройте вкладку и откройте заново

### Перезапустите серверы:

```bash
# Терминал 1 (Backend)
Ctrl+C
npm run dev

# Терминал 2 (Frontend)  
Ctrl+C
npm run dev
```
