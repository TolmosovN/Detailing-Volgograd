# 📊 ЭТАП 7: Админ-панель

## 🎯 Цель:
Создать панель управления для администратора, где можно:
- Просматривать все записи
- Изменять статус записей
- Видеть статистику
- Управлять услугами

---

## 🔐 Что реализуем:

### Backend (5 компонентов):

1. **Middleware для проверки роли админа**
   - `server/src/middleware/adminAuth.ts`
   - Проверяет, что пользователь - админ

2. **Контроллер для админских операций**
   - `server/src/controllers/adminController.ts`
   - Статистика (количество записей, популярные услуги)
   - Все записи с фильтрацией
   - Обновление статуса записи
   - CRUD операции с услугами

3. **Роуты для админ-панели**
   - `server/src/routes/admin.ts`
   - GET `/api/admin/stats` - статистика
   - GET `/api/admin/bookings` - все записи
   - PATCH `/api/admin/bookings/:id/status` - изменить статус
   - POST/PUT/DELETE `/api/admin/services` - управление услугами

4. **Обновление существующих контроллеров**
   - Добавить фильтры в `getAllBookings`

5. **Создание админа в базе**
   - Обновить seed.ts для создания админа

---

### Frontend (8 компонентов):

1. **Middleware для проверки роли**
   - Защита роута `/admin` от обычных пользователей

2. **Страница админ-панели**
   - `client/app/admin/page.tsx`
   - Дашборд со статистикой

3. **Компонент статистики**
   - `client/src/features/admin/components/StatsCards.tsx`
   - Карточки с цифрами

4. **Таблица записей**
   - `client/src/features/admin/components/BookingsTable.tsx`
   - Все записи с возможностью изменения статуса

5. **Модальное окно управления услугами**
   - `client/src/features/admin/components/ServicesManager.tsx`
   - Добавление/редактирование/удаление услуг

6. **API клиент для админа**
   - `client/src/shared/api/adminApi.ts`

7. **Обновление Header**
   - Добавить ссылку "Админ" для админов

8. **Навигация в админ-панели**
   - Вкладки: Дашборд, Записи, Услуги

## 📊 Функции:

### 1. Статистика:
- ✅ Общее количество записей
- ✅ Новые записи (за последние 24 часа)
- ✅ Ожидают подтверждения
- ✅ Выполненные за месяц
- ✅ Общий доход
- ✅ Популярные услуги (топ-3)

### 2. Управление записями:
- ✅ Просмотр всех записей
- ✅ Фильтр по статусу (все, новые, подтвержденные, выполненные)
- ✅ Фильтр по дате
- ✅ Поиск по имени/телефону
- ✅ Изменение статуса (подтвердить, отменить, выполнено)
- ✅ Просмотр деталей клиента

### 3. Управление услугами:
- ✅ Список всех услуг
- ✅ Добавить новую услугу
- ✅ Редактировать существующую
- ✅ Деактивировать услугу (не удаляем, чтобы история записей сохранилась)
- ✅ Изменить цену и длительность

## 🔒 Безопасность:

1. **Middleware проверки роли**
   ```typescript
   // Только пользователи с role='ADMIN' могут заходить
   if (req.user.role !== 'ADMIN') {
     return res.status(403).json({ error: 'Доступ запрещён' });
   }
   ```

2. **Frontend защита**
   ```typescript
   // Редирект, если не админ
   if (user.role !== 'ADMIN') {
     router.push('/');
   }
   ```

3. **Валидация на backend**
   - Все admin роуты защищены двумя middleware:
     1. `authMiddleware` - проверка токена
     2. `adminAuthMiddleware` - проверка роли
