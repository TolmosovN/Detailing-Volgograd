## 🔐 API Endpoints:

### Авторизация:
- `POST /api/auth/register` - Регистрация нового пользователя
- `POST /api/auth/login` - Вход в систему

### Пользователи (защищённые):
- `GET /api/users/me` - Получить данные пользователя
- `PUT /api/users/me` - Обновить профиль
- `GET /api/users/me/bookings` - Получить мои записи

### Записи:
- `POST /api/bookings` - Создать запись (опционально авторизованная)
- `GET /api/bookings` - Получить все записи (для админа)

## 🧪 ТЕСТИРОВАНИЕ

### 1. Проверьте, что серверы работают:

**Backend** (должен работать):
```bash
cd server
npm run dev
# Вы должны видеть: 🚀 Сервер запущен на http://localhost:3001
```

**Frontend** (должен скомпилироваться):
```bash
cd client
npm run dev
# Если не запущен - запустите
```

---

### 2. Тест регистрации:

1. Откройте http://localhost:3000
2. Кликните **"Войти"** в header
3. Внизу кликните **"Зарегистрироваться"**
4. Заполните форму:
   - **Имя**: Иван Иванов
   - **Email**: ivan@test.ru
   - **Телефон**: +79991234567
   - **Пароль**: 123456
   - **Подтверждение**: 123456
5. Нажмите **"Зарегистрироваться"**

**Ожидаемый результат:**
- Вы автоматически авторизованы
- Перенаправлены на `/profile`
- Видите личный кабинет с вашими данными
- В header вместо "Войти" показывается ваше имя

---

### 3. Тест выхода и входа:

1. В личном кабинете нажмите **"Выйти"**
2. Вы перенаправлены на главную
3. В header снова **"Войти"**
4. Кликните **"Войти"**
5. Введите:
   - **Email**: ivan@test.ru
   - **Пароль**: 123456
6. Нажмите **"Войти"**

**Ожидаемый результат:**
- Вы авторизованы
- Перенаправлены в `/profile`
- Ваши данные загружены

---

### 4. Тест автозаполнения формы записи:

1. Будучи авторизованным, перейдите в **"Записаться"**
2. Обратите внимание на форму

**Ожидаемый результат:**
- Поля **"Имя"**, **"Телефон"**, **"Email"** автоматически заполнены вашими данными!
- Вам нужно выбрать только услугу, дату и время

3. Создайте запись
4. Вернитесь в **"Профиль"**

**Ожидаемый результат:**
- Ваша запись отображается в разделе "Мои записи"!

---

### 5. Тест защиты роутов:

1. Выйдите из системы
2. Попробуйте открыть http://localhost:3000/profile

**Ожидаемый результат:**
- Вы автоматически перенаправлены на `/login`
- Страница профиля недоступна без авторизации

---

### 6. Тест токена (продвинутое):

1. Авторизуйтесь
2. Откройте DevTools (F12)
3. Перейдите в **Application** → **Local Storage** → http://localhost:3000
4. Вы должны увидеть:
   - `token` - JWT токен
   - `user` - Данные пользователя в JSON

5. Перезагрузите страницу (F5)

**Ожидаемый результат:**
- Вы остались авторизованы!
- Система проверила токен автоматически

6. Удалите `token` из localStorage
7. Перезагрузите страницу

**Ожидаемый результат:**
- Вы автоматически вышли
- Перенаправлены на главную

## 🐛 Известные ограничения:

1. **Токен в localStorage** - не самый безопасный вариант (для production лучше httpOnly cookies)
2. **Нет refresh токенов** - при истечении токена нужно войти заново
3. **Временный userId=1** для гостевых записей - нужно будет очистить при добавлении гостевых аккаунтов

Эти ограничения можно устранить на следующих этапах!
